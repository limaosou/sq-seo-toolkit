== 外部服务说明 ==

默认安装后，本插件不会向任何第三方发起请求。以下三项只有在你主动填写站点与 token 之后才会启用：

* 百度搜索资源平台「普通收录 → API 推送」（data.zz.baidu.com）：文章发布/更新时把该文章 URL 提交给百度。
* 神马搜索「MIP 数据提交」（data.zhanzhang.sm.cn）：同上，提交给神马搜索，选填。
* IndexNow（api.indexnow.org）：文章发布/更新时把 URL 提交给 Bing / Yandex 等，留空即关闭。

所有 token 只保存在你自己站点的数据库（sqseo_options）里，不会发送给作者或任何统计服务；停用或删除插件后按「卸载」一节清理。

== 功能 ==

* TDK 管理：首页标题/关键词、分类标题模板（支持 {分类名} {站名} 变量）、文章描述可选接管
* Sitemap：/sitemap.xml，仅含文章 + 分类，自动排除标签/作者，防止薄页面进地图
* robots.txt：一键放行 AI 爬虫（GPTBot / ClaudeBot / PerplexityBot / Bytespider 等 17 个）
* llms.txt：后台直接编辑，留空自动生成基础版
* OG / Twitter 社交卡片：微信、微博、Twitter 分享出图文卡片
* JSON-LD 结构化数据：WebSite + Organization + Article + BreadcrumbList
* 图片 ALT 自动补全：正文图片缺 alt 自动补文章标题
* 百度主动推送：发布/更新文章自动推送，免授权，直接用百度官方 API
* 神马搜索推送：发布/更新文章自动推神马（选填，适合移动端流量）
* 推送日志页：查看每次百度/神马推送结果，支持手动补推
* 抓取日志页：主流搜索引擎与 AI 爬虫抓取记录 + 404 死链监控
* 自动内链：关键词自动加站内链接，每词每篇 1 次、总数可限
* HTML 地图：[sqseo_html_sitemap] 短代码生成访客版站点地图
* IndexNow 推送：文章发布自动推 Bing/Yandex，密钥验证文件自动生成
* llms-full.txt：全站文章标题+摘要索引，供 AI 爬虫一次读完全站
* 插件冲突检测：检测到其他 SEO 插件运行时后台醒目提醒
* 薄页 noindex：标签/作者/搜索/日期页输出 noindex,follow
* 文章编辑框：每篇文章自定义标题/关键词/描述（描述受「接管」开关控制，防止与主题重复）
* FAQ 问答：文章末尾渲染可见问答区块 + FAQPage 结构化数据（AI 搜索最易引用的格式）
* 分类排除：勾选的分类及其文章不进 sitemap 与 llms.txt
* 301 重定向：404 死链一键加跳转规则，权重不流失（支持完整 URL 粘贴、命中计数）
* 站长平台验证码：百度/必应/神马/搜狗/360 验证 meta 一处填写自动输出
* 内容体检：超期未更新文章清单（可设阈值）+ 文章内链外链批量死链扫描
* 备份/迁移：全部设置与重定向规则一键导出/导入 JSON
* 文章列表 SEO 列：一眼看出哪些文章漏配标题/描述

== 安装 ==

1. 后台 → 插件 → 安装插件 → 上传插件 → 选择 sanqi-seo-2.3.8.zip → 现在安装 → 启用
2. 左侧菜单出现「SQ SEO」→ 进入填写设置 → 保存
3. 若站点装了页面缓存插件或 CDN，清一次缓存后前台 Ctrl+F5 硬刷新验证

== 注意 ==

* 启用前请停用其他 SEO 插件（Rank Math / Yoast / SEO合集），同屏只跑一个
* 「接管 description」默认关闭：若主题已在输出 description，保持关闭即可，不会产生重复 meta
* robots.txt 的 AI 放行仅在「根目录无物理 robots.txt 文件」时生效（WordPress 动态生成模式）

== 卸载与升级 ==

* 卸载：后台「插件 → 已安装插件 → 删除」会执行 uninstall.php，清除全部设置、日志、重定向规则、文章 meta 与定时任务。删除前请到「SQ SEO → 备份 / 迁移」导出 JSON 留底。
* 覆盖升级：从旧版 sanqi-seo 直接覆盖文件即可，设置项 sqseo_options 与文件夹名、文本域均保持兼容，不会丢配置。
* 已有其它 SEO 插件（Yoast / Rank Math / SEO合集）时请只启用其中一个，避免重复输出 meta 与结构化数据。
